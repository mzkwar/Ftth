# كشف المحفظة (APK)

1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي (بما فيها المجلد المخفي .github).
2. افتح تبويب Actions، اختر Build APK، ثم Run workflow (أو يعمل تلقائياً عند الرفع).
3. بعد انتهاء البناء (نحو 5 دقائق) افتح التشغيل ونزّل الملف wallet-statement-apk، وفيه app-debug.apk.
4. انقل الملف إلى الهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة» عند الطلب).

التطبيق يعمل دون إنترنت. زر «حفظ كصورة» يفتح قائمة المشاركة لحفظ الصورة في المعرض أو إرسالها.
